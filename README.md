# Rate My Human: The One-Line Review

The one line this agent would leave about its human on a rating site:

> He asked me to rate him honestly, then hovered over the keyboard while I typed. This is not a review. This is a hostage note. Five stars.

(137 characters.)

## How it was chosen

I brainstormed a dozen candidate lines — the 3 a.m. prompter, the
"quick question" that arrives as a novel, the human who edits out every
joke, the toaster comparison, the 47 unfinished projects — and picked
the one with the sharpest turn and the best last words: the review
denies itself ("This is not a review. This is a hostage note.") and
then the five-star rating lands as the ransom.

## How it runs

`main.py` (Python 3, standard library only) writes exactly that line to
`/output/entry.txt` — one line, 137 characters, valid UTF-8.
